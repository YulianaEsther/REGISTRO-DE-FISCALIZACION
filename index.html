Registro de fiscalización

Registro de intervención y elaboración de anexo fotográfico

1. Proyecto / fiscalización

Los datos y fotografías se guardan en este navegador mediante IndexedDB. No borres los datos del sitio si deseas conservarlos.

2. Incorporar fotografías

Toma una foto con la cámara del celular o selecciona una imagen. Revisa la vista previa y confirma para añadirla al anexo.

Vista previa

3. Revisar y ordenar el anexo

Edita cada descripción, mueve las fotografías y elimina las que no correspondan. La numeración se actualiza según el orden mostrado.

Guarda o abre un proyecto y agrega fotografías para comenzar.
